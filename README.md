# Telegram Mini App Payment API

A powerful and flexible payment API implementation that supports deposit and withdrawal operations, built with .NET.

## Prerequisites

- .NET 9.0 SDK or later
- Visual Studio 2022 or VS Code

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/tg-payment-api.git
cd tg-payment-api
```

2. Restore dependencies:

```bash
dotnet restore
```

3. Configure application settings:

```bash
cp appsettings.example.json appsettings.json
```
